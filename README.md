# PingLess for Android

اپلیکیشن اندروید PingLess، بر پایه [v2rayNG](https://github.com/2dust/v2rayNG) (هسته Xray، پشتیبانی کامل از XHTTP).

## قابلیت‌ها
- **فعال‌سازی با کد:** کد را از ربات تلگرام (بخش «سرویس‌های من» ← «کد فعال‌سازی اپلیکیشن») بگیرید و در اپ وارد کنید.
- **⚡️ اتصال خودکار:** همه سرورها هر ۳۰ دقیقه پینگ گرفته می‌شوند و ترافیک خودکار از سریع‌ترین سرور عبور می‌کند. اگر یک سرور قطع شود، سرور بعدی جایش را می‌گیرد.
- **🌍 انتخاب دستی:** لیست لوکیشن‌ها با تست پینگ؛ کاربر خودش انتخاب می‌کند.
- **🔗 اشتراک دلخواه:** افزودن هر لینک اشتراک دیگری.
- سایت‌های ایرانی مستقیم (بدون VPN) باز می‌شوند.

## ساخت APK
1. این پوشه را در یک مخزن **عمومی (Public)** گیت‌هاب آپلود کنید.
2. در Settings ← Secrets and variables ← Actions، دو Secret بسازید: `KEYSTORE_BASE64` و `KEYSTORE_PASSWORD` (مقدارها در فایل signing-key.txt).
3. در تب **Actions**، workflow «Build PingLess APK» را با **Run workflow** اجرا کنید.
4. حدود ۲۰ دقیقه بعد، فایل APK در پایین صفحه همان اجرا، بخش **Artifacts** است. فایل `universal` روی همه گوشی‌ها نصب می‌شود.

## تنظیمات
آدرس API در `overlay/java/com/v2ray/ang/pingless/ActivationActivity.kt` (متغیر `API_BASE`) است.
